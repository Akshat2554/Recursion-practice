# Recursion Practice

A collection of classic recursive algorithms implemented in Java from scratch.
Built as part of my journey learning data structures and algorithms.

## Implementations

- **Factorial** — computes n! recursively
- **Fibonacci** — returns the nth Fibonacci number
- **Sum Array** — sums all elements in an array without loops
- **Reverse String** — reverses a string character by character
- **Binary Search** — finds a target in a sorted array in O(log n) time
- **Power** — computes base^exp using fast exponentiation

## What I learned

Writing these from scratch made me understand the two parts of every recursive function:
- The base case — when to stop
- The recursive case — how to make the problem smaller each time

I did recursion as part of my coursework but it was pretty shaky so I practiced some common problems to solidify recursion  

## How to run

```bash
javac Fibonacci.java
java Fibonacci
```
